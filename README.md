# Mon Site Web

## À propos du projet

J'ai travaillé sur ce projet pour transformer le site en plusieurs pages et faciliter la navigation entre elles.

## Ce que j'ai fait

Découpage du site en plusieurs pages HTML.
Ajout du Header et du Footer sur chaque page.
Correction des liens entre les différentes pages.
Mise en place de la navigation d'une page à une autre.
Ajout d'un lien actif pour montrer la page actuelle.
Conservation du même style CSS pour toutes les pages.
Création et mise en forme de la page Contact pour permettre aux visiteurs de contacter l'équipe du site.

## Ce que j'ai appris

Pendant ce projet, j'ai appris les bases de HTML et plusieurs notions de CSS.

J'ai aussi appris quelques notions de Git et GitHub, comme créer un repository, gérer les branches et envoyer mon projet sur GitHub.
